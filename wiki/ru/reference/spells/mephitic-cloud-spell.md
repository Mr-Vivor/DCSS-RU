# Зловонное облако

**English:** Mephitic Cloud spell

Создаёт хрупкую колбу, которая взрывается недолговечными облаками ядовитых испарений. Они могут вызвать замешательство у существ без сопротивления яду. Более крепкие и опытные существа реже поддаются этому воздействию.

Название и описание берутся из общих словарей игры и вики.

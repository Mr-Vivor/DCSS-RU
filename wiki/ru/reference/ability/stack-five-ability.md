# Сложить пять

**English:** Stack Five ability

Вытягивает пять карт из выбранных вами колод и позволяет расположить их в любом порядке. Затем их можно разыгрывать в установленной последовательности. Повторное применение сбрасывает текущую стопку.

Название и описание берутся из общих словарей игры и вики.

# Тепловой двигатель Максвелла

**English:** Maxwell's thermic engine

Странный меч: одно лезвие обжигающе горячее, другое ледяное. При попаданиях разница температур увеличивается. Причина неизвестна, но, по слухам, здесь замешаны потусторонние силы.

## Особые свойства

- **Заморозка:** Замораживает жертв, добавляя четверть урона, прошедшего сквозь их броню. Также может замедлять хладнокровных существ.
- **Разгон:** Становится эффективнее при попаданиях. Со временем усиление угасает.

Название и описание берутся из общих словарей игры и вики.

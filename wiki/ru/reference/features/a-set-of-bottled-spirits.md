# Набор бутылок со спиртным

**English:** A set of bottled spirits

Набор разных алкогольных напитков с истёртыми этикетками. К несчастью, сохраняющая магия, запечатывающая каждую бутылку, не позволяет попробовать содержимое, не разбив её.

Название и описание берутся из общих словарей игры и вики.

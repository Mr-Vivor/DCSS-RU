# Лернейская гидра

**English:** Lernaean hydra

Огромная тварь, сильнейшая из гидр, печально известная по мифам и легендам. Она несётся по воде быстрее бегущего человека, отбрасывая деревья словно спички. Её многочисленные головы непрестанно истекают слюной и скрежещут зубами, пока она ищет добычу, способную утолить бездонный голод.

Название и описание берутся из общих словарей игры и вики.

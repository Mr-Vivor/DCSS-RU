# Молниевая чешуя

**English:** lightning scales

Набор броневых пластин для существа с длинной чешуйчатой нижней частью тела. Тихо потрескивая электричеством, резко усиливает способность владельца преодолевать расстояния.

## Особые свойства

- **Быстроходность:** Позволяет владельцу быстрее передвигаться.

Название и описание берутся из общих словарей игры и вики.

# Зуб вампира

**English:** Vampire's Tooth

Быстрый клинок цвета слоновой кости, словно сделанный из зуба громадного хищного существа. Смертоносное вампирское оружие.

## Особые свойства

- **Сверхвампиризм:** При ранении живого врага иногда исцеляет владельца на полную величину нанесённого урона.

Название и описание берутся из общих словарей игры и вики.

# Теленцефалон

**English:** telencephalon

Заброшенный магический опыт с первоначальной целью, непостижимой даже по меркам подобных опытов. Он состоит из магического кристалла, сросшегося с мутировавшей мозговой тканью, и беспорядочно плавает сам по себе, непрерывно искря.

При тяжёлых повреждениях он высвобождает мощную телекинетическую ударную волну, отбрасывающую окружающих и вызывающую непреодолимое замешательство у всех, кто мог бы ему навредить.

Название и описание берутся из общих словарей игры и вики.

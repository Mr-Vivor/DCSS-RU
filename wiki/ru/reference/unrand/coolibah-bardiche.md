# Бердыш из кулибы

**English:** coolibah bardiche

Массивное древковое оружие, целиком вырезанное из дерева кулиба. Деревянное лезвие ничуть не менее остро, а попавшие в зачарованные ветви вскоре почувствуют себя как дома в болоте, из которого выросло это смертоносное оружие.

Название и описание берутся из общих словарей игры и вики.

# Как считать объём перевода

Запуск: `python tools/ru/translation_status.py` (не требует сборки игры).
Опция `--json путь.json` сохраняет полный отчёт.

На 29 октября 2026 года русская версия содержит текст для **52,6% объёма
учтённых исходных текстов**, если взвешивать записи по числу английских слов.
По количеству записей получается 81,3%: короткие подписи заметно повышают эту
цифру, поэтому для оценки оставшейся работы используем объём текста.

Это доступность русских текстов, включая унаследованные черновики. Она не
означает, что 52,6% всей игры переведено и проверено. В отчёт входят выбранные
каталоги системных строк, базы описаний и перечисленные в скрипте базы реплик.
Не входят строки, собираемые непосредственно в C++/Lua/JavaScript, случайные
имена и частота появления сообщений в игре. Новые шаблоны из исходников,
добавленные сверх старых каталогов, пока также не входят в этот знаменатель.
Присутствие кириллицы не проверяет полноту отдельной записи и актуальность
описанной механики.

| Раздел | Доля исходного объёма с русским текстом |
| --- | ---: |
| Описания предметов | 47,2% |
| Описания заклинаний | 25,7% |
| Описания способностей | 21,9% |
| Описания монстров | 31,3% |
| Все базы описаний | 47,8% |
| Реплики и прочий художественный текст | 4,1% |

Поле `fingerprinted_description_entries` учитывает только записи реестра
`descriptions.json`, для которых генератор сверяет хеш текущего английского
источника. Это не счётчик всех ручных проверок: для системных строк и других
групп действуют отдельные реестры. Полностью заполненный старый каталог
`messages.txt` также не означает полноту системного перевода современной игры.

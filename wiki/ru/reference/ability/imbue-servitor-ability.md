# Наделить слугу заклинанием

**English:** Imbue Servitor ability

Позволяет выбрать одно из ваших разрушительных заклинаний для прислужников искры заклинаний, которых вы создадите в дальнейшем. Оно заменяет ранее переданное им заклинание. Вы должны уметь самостоятельно применять выбранное заклинание с вероятностью неудачи не выше 20%.

Передача занимает несколько ходов. Если у вас уже есть действующий прислужник, он будет отозван.

Название и описание берутся из общих словарей игры и вики.

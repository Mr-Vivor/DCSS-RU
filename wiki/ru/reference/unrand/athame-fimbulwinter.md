# Атам «Фимбульвинтер»

**English:** athame "Fimbulwinter"

Орудие ужаса, созданное одними из самых печально известных пророков Казлала, чтобы вызвать трёхлетнюю зиму перед концом времён. Охлаждённые его владельцем почувствуют ледяную хватку судьбы на горле.

Как и у всех атамов, базовый урон его ударов повышен против целей с вредными состояниями, кроме яда.

Название и описание берутся из общих словарей игры и вики.

# Искажение времени

**English:** Temporal Distortion ability

Искажает течение времени вокруг вас: для окружающих существ проходит несколько ходов, пока вы на мгновение исчезаете из потока времени. Это позволяет монстрам приблизиться без возможности атаковать вас в этот промежуток.

Название и описание берутся из общих словарей игры и вики.

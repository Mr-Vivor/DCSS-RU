# Аварийный люк в полу

**English:** An escape hatch in the floor

Односторонний люк с пружинным механизмом, встроенный в пол подземелья. Он позволяет искателю приключений, окружённому врагами, сменить опасности этого этажа на опасности следующего.

Название и описание берутся из общих словарей игры и вики.

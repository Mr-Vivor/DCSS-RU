# Связующий миры

**English:** worldbinder

Облако густого тумана, из которого непрерывно тянутся бледные слабые когти, чтобы снова раствориться в нём. При угрозе оно вызывает существ, изгнанных в пустоту между реальностями, и использует их для защиты.

Название и описание берутся из общих словарей игры и вики.

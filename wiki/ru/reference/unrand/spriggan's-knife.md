# Нож сприггана

**English:** Spriggan's Knife

Изящный маленький нож, сделанный спригганами, для спригганов или, возможно, из спригганов. Во всяком случае, с этим волшебным народцем он как-то связан.

## Особые свойства

- **Скрытый удар:** Эффективнее при скрытых ударах по не замечающим вас врагам; иногда считает их полностью беспомощными.

Название и описание берутся из общих словарей игры и вики.

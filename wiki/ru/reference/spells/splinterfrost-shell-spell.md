# Морозный панцирь

**English:** Splinterfrost Shell spell

Возводит вокруг заклинателя полукруглую оболочку из укреплённого льда, по возможности оттесняя существ, чтобы освободить для неё место.

Преграда прочна, но способна раскалываться: каждый уничтоженный участок выпускает залп ледяных снарядов в того, кто его разрушил.

Если заклинатель отойдёт слишком далеко, преграда быстро растает.

Название и описание берутся из общих словарей игры и вики.

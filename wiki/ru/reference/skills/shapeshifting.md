# Оборотничество

**English:** Shapeshifting

Оборотничество позволяет менять собственный облик с помощью волшебных талисманов. Достаточный навык открывает более мощные формы без тяжёлого ущерба здоровью. Он также усиливает большинство форм; конкретный эффект зависит от формы.

Название и описание берутся из общих словарей игры и вики.

# Вырвать страдальцев из земли

**English:** Unearth Wretches ability

Вызывает из некрополя Кикубаакудги существ на грани смерти, предоставляя обильный материал для любой некромантии. Их количество и качество зависят от навыка Некромантии.

Название и описание берутся из общих словарей игры и вики.

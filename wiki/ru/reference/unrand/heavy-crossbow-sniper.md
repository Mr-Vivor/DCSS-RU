# Тяжёлый арбалет «Снайпер»

**English:** heavy crossbow "Sniper"

Священное оружие Тот-Моса, первого апостола Ашензари. Даёт владельцу частицу зрения самого Ашензари, благодаря чему каждый выстрел безошибочно находит цель.

## Особые свойства

- **Точность+∞:** Никогда не промахивается по цели.

Название и описание берутся из общих словарей игры и вики.

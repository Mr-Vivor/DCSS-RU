# Плащ из крысиных шкур

**English:** ratskin cloak

Плащ, сшитый из шкур сотен адских крыс чародейкой, у которой было слишком много свободного времени. Внутри каким-то образом скрывается ещё множество крыс, способных выбежать на помощь владельцу.

## Особые свойства

- ***Крысы:** Когда владелец ранен, из плаща могут выбежать крысы ему на помощь.

Название и описание берутся из общих словарей игры и вики.

# Хрустальный шар Вукад Му

**English:** crystal ball of Wucad Mu

Сфера безупречного хрусталя, сформированная бесчисленными мантрами. При сосредоточенном взгляде на неё граница между «я» и «другим» порой будто размывается. Для джиннов он совершенно бесполезен.

## Особые свойства

- **Подпитка:** Когда успешное заклинание вызывает приток магии из шара, он может дополнительно вытянуть магию из других врагов в поле зрения. Вероятность растёт с уровнем заклинания.

Название и описание берутся из общих словарей игры и вики.

# Пол с оружейной инкрустацией

**English:** A weapon-inlaid floor

Эльфийская декоративная инкрустация оружием отмечает Зал Клинков. Отсюда происходит немало острейшего оружия Подземелья, магически оживлённого, чтобы доказать свою смертоносность возможным ворам.

Название и описание берутся из общих словарей игры и вики.

# Офан

**English:** ophan

Существо из небесных сфер: колесо внутри другого колеса, и оба усеяны глазами. По нему мерцают странные языки священного пламени. Его бесчисленные глаза высвечивают жертву и клеймят её как отступника — добычу для союзников этого существа.

Название и описание берутся из общих словарей игры и вики.

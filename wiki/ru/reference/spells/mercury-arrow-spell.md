# Ртутная стрела

**English:** Mercury Arrow spell

Создаёт стрелу из чистой ртути, которая наносит цели прямой урон ядом и может ненадолго ослабить её атаки в ближнем бою.

Физический удар стрелы причиняет небольшой урон даже существам с иммунитетом к яду. Ослабление может перекинуться на соседние цели и полностью игнорирует сопротивление яду.

Название и описание берутся из общих словарей игры и вики.

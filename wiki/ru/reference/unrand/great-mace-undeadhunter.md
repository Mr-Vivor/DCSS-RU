# Огромная булава «Охотник на нежить»

**English:** great mace "Undeadhunter"

Оружие с магией, разрушающей силы, которые удерживают нежить в едином целом. По легендам, давным-давно владыка-лич создал много таких орудий, чтобы обеспечить верность своих мёртвых слуг. Увы, эта булава, возможно, последняя уцелевшая.

## Особые свойства

- **Против нежити:** Наносит значительно больше урона нежити.

Название и описание берутся из общих словарей игры и вики.

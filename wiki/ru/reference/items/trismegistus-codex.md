# Кодекс Трисмегиста

**English:** trismegistus codex

Книга магических заклинаний,
написанная чародеем, одержимым
тайным смыслом чисел.
Всё здесь упорядочено:
длина каждого предложения,
общая структура изложения.
Не вполне ясно,
находил ли автор
такое устройство полезным.

Название и описание берутся из общих словарей игры и вики.

# Лягушачьи ноги

**English:** frog-like legs mutation

Мощные ноги позволяют мгновенно перепрыгивать на небольшое расстояние с помощью <input>$cmd[CMD_USE_ABILITY]</input>, хотя обычная ходьба у вас медленнее средней.

Второй уровень мутации увеличивает дальность прыжка.

Название и описание берутся из общих словарей игры и вики.

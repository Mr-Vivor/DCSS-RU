# Отказ от свитков

**English:** renounce scrolls mutation

Вы отказываетесь читать свитки в бою без тяжёлых ран. Пока в поле зрения есть враги и ещё несколько ходов после этого вы не можете читать свитки, если здоровье не опустилось ниже 50% максимума.

Название и описание берутся из общих словарей игры и вики.

# Копьё «Вирмбейн»

**English:** lance "Wyrmbane"

Зачарованное копьё, смертоносное для всех драконов. Становится сильнее каждый раз, когда наносит смертельный удар могучему дракону. Чем могущественнее копьё, тем труднее найти достойного противника.

## Особые свойства

- **Против драконов:** Наносит дополнительный урон драконам и драконидам.

Название и описание берутся из общих словарей игры и вики.

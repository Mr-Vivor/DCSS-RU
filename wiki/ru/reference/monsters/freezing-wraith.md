# Леденящий призрак

**English:** freezing wraith

Бестелесный скелетообразный призрак в облаке морозного воздуха — вероятно, останки неудачливого искателя приключений. Теперь он медленно парит по Подземелью, желая обречь других на ту же участь.

Название и описание берутся из общих словарей игры и вики.

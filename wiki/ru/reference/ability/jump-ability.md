# Прыжок

**English:** Jump ability

Позволяет совершить молниеносный прыжок по воздуху. Выбрать место приземления нельзя, но движение столь резкое и ловкое, что до вашего следующего действия ни один монстр не сможет попасть по вам. Многие и вовсе потеряют вас из виду.

Между применениями нужно немного времени на восстановление.

Название и описание берутся из общих словарей игры и вики.

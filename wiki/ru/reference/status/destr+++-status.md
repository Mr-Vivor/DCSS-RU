# Разруш.+++

**English:** Destr+++ status

При последовательных применениях способности «Высвободить разрушительную силу» её мощь нарастает.

Следующее применение выпустит залп дополнительных магических снарядов по случайным целям, после чего накопленное усиление сбросится.

Название и описание берутся из общих словарей игры и вики.

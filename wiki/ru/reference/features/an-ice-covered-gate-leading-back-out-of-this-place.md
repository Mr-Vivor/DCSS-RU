# Покрытые льдом врата наружу

**English:** An ice covered gate leading back out of this place

Портал, ведущий обратно туда, откуда вы пришли. Его магия сдерживает лёд и не даёт ему перекрыть врата. Пройдя через портал, вы уже не сможете вернуться сюда.

Название и описание берутся из общих словарей игры и вики.

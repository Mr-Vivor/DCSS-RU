# Драконья жила земли

**English:** an earthen dragon vein

Обнажённая силовая линия земной магии. Наступив на неё, можно вызвать ударные волны, которые ранят двух ближайших врагов. Дальние и летающие враги получают значительно меньше урона.

Название и описание берутся из общих словарей игры и вики.

# Длинный лук «Зефир»

**English:** longbow "Zephyr"

Золотой лук с тетивой из пряди волос самого Западного ветра. По преданию, его создали в дар безответной любви. Даже через столетия после её безвременной гибели в лёгком ветерке вокруг владельца всё ещё чувствуется тоска.

Название и описание берутся из общих словарей игры и вики.

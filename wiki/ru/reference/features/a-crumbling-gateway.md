# Разрушающиеся врата

**English:** A crumbling gateway

Покрытая солью арка с высеченными мольбами к добрым богам удержать заточённое за ней зло. Время наконец разрушило её былую защиту, и из далёких земель по ту сторону веет горьким ветром.

Название и описание берутся из общих словарей игры и вики.

# Russian WebTiles lobby

This is a returning player's game menu, not a marketing landing page.

- Centre the original DCSS title mark and three equal-size actions: play/continue, tutorial, wiki.
- Use the game's DejaVu Sans Mono and original tiles. The menu should belong beside the dungeon UI.
- Show the actual running version on the game actions. Preserve save-state text, disabled slots and rc settings.
- Keep login below the menu, and account/settings links secondary.
- Show the real spectator table when players are present. Do not invent activity, statistics or status labels.
- No promotional headlines, oversized serif type, feature cards, gradient backdrops, floating art, badge-shaped version labels or hover lifts.
- All lobby styling stays scoped away from the dungeon and authentication prompt.
- Wiki design is separate and must not change as part of a lobby revision.

Reviewed using anti-ai-ui and audience-ui-review from https://github.com/pc-style/SLOP-STOP.

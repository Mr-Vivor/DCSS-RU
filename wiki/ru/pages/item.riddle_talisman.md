# Талисман загадки

**English:** riddle talisman
**ID:** `item.riddle_talisman`

## Описание в игре

Замысловатая шкатулка-головоломка с непостижимым призом внутри. Превращает владельца в любящего загадки сфинкса. В этой форме владелец {{
    if you.race() == "Felid" then
        return "обычно может носить плащ и бардинг (хотя ваш" ..
               " собственный малый размер этому мешает)"
    else
        return "может носить плащ и бардинг"
    end
}}, а его атаки ближнего боя обрушивают на цель мощные ветры. Их урон растёт с каждой свободной клеткой рядом с врагом. Форма также облегчает сотворение Проклятий и позволяет игнорировать часть Воли противника.

Увы, любовь к загадкам столь навязчива, что даже закалённый искатель приключений не удержится от желания задавать их новым встреченным врагам, как бы неразумно это ни было.

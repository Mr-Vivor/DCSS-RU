# Шагающий перегонный куб

**English:** walking alembic

Подвижная боевая алхимическая мануфактура, использующая трение ближнего боя для приготовления разнообразных полезных зелий. Накопив достаточно тепла для завершения синтеза, она автоматически раздаёт готовые зелья ближайшим союзникам и распадается.

Название и описание берутся из общих словарей игры и вики.

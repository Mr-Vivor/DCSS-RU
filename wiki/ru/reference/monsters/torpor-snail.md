# Улитка оцепенения

**English:** torpor snail

Неповоротливый брюхоногий моллюск с твёрдой как камень раковиной. Говорят, он каким-то образом связан с Чейбриадосом. Одно его присутствие замедляет неосторожных искателей приключений, превращая их в лёгкую добычу для страшной, непрестанно скрежещущей тёрки во рту улитки.

Название и описание берутся из общих словарей игры и вики.

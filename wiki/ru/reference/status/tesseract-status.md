# Тессеракт

**English:** Tesseract status

Безграничный тессеракт стягивает силы из параллельной реальности. Новые монстры будут непрерывно появляться в случайных местах этажа, пока один из двух тессерактов не будет уничтожен. Если это продолжится очень долго, монстры иногда начнут появляться рядом с вами.

Название и описание берутся из общих словарей игры и вики.

# DCSS-RU

Русский форк Dungeon Crawl Stone Soup. Первый проход: понятный перевод с постепенным исправлением падежей и терминов.

Основа: crawl/crawl, trunk от 25 октября 2026 года (`60e87af`). Языковой слой перенесён из [Alphabet Soup](https://github.com/powerbf/alphabet-soup/tree/i18n-master), коммит `c15f1bd`, с сохранением исходной атрибуции. Механика игры следует выбранной версии upstream.

## Текущее состояние

- Русский включён по умолчанию; для английского укажите `language = en` в настройках.
- Общий словарь: 92 монстра и 99 предметов, формы шести падежей и числа.
- Общие названия: 27 видов, 28 предысторий, 29 навыков, 26 богов и основные учебные заклинания.
- Заполнены 25 системных каталогов — 5847 разных ключей интерфейса, состояний, способностей, глаголов, частей тела и прочих статичных подписей.
- По контексту вычитаны весь общий интерфейс (477 строк), состояния (527), подписи предметов (187), навыки (65) и названия характеристик. Исправлено 745 статичных перевода, включая ошибочные значения `Will`, `AC`, `Wear`, `Take off`, `Train` и склеенные соседние записи.
- Переведены все 27 описаний видов, 28 предысторий, 82 записи богов, 88 записей обучения, 217 подсказок, 98 команд, справка и FAQ. Массовые дополнения пока черновые; основные описания персонажей и вступления богов вычитаны отдельно.
- Дополнены общие сообщения исследования, отдыха, экипировки, колдовства, повышения уровня и веры. Их словарь — `localization/ru/system-messages.json`; переведены также прямые сообщения внутри кода учебных карт.
- Названия и описания персонажей и богов также публикуются в `wiki/ru/characters/` из тех же источников, что использует игра.
- Словарь системных сообщений расширен до 6886 записей. Переведены все 6305 шаблонов импортированного английского каталога: действия, бой, монстры, заклинания, боги, карты, окна осмотра и отладка. Это полное покрытие конкретного каталога, а не всего текста текущего движка.
- Добавлены актуальные строки создания персонажа, инвентаря, тренировки и сравнения снаряжения. Отдельно переведены все 167 вариантов `miscname.txt`: вступления о Сфере Зота, призыв и атмосферные сообщения Ада. Имена игроков сохраняются, вид и предыстория в приветствии переводятся отдельно.
- Отдельная проверка текущего `ability.cc` покрывает все 161 название способности, включая 49 названий вне старого каталога. Исправлены машинные ошибки вроде «Срок службы» у `Drain Life`; названия в меню и сообщениях согласованы. Для боевых подстановок используются падежи, для движений — личные формы глаголов, для частей тела добавлен родительный падеж.
- С текущей версией сверено 181 описание предметов: оружие, доспехи, щиты, снаряды, посохи, активируемые устройства, зелья, свитки, палочки, кольца и амулеты. Также сверены все 29 описаний навыков и все 80 описаний особых свойств снаряжения. Они находятся в `localization/ru/descriptions.json`; 209 справочных страниц в `wiki/ru/reference/` используют те же названия и тексты.
- Исправлен перенос цветного текста: ширина UTF-8 измеряется в видимых символах, а не байтах. Длинные слова в браузерном окне сообщений тоже переносятся.
- В `wiki/ru/` генерируются карточки терминов и данные будущей вики. Для ледяного дракона, зелья исцеления и свитка телепортации добавлены первые статьи; остальные карточки пока черновые.
- Отсутствующий перевод отображается на английском. Неточные формы исправляются постепенно.

Это начало локализации, а не заявление о переводе 50% игры. Тысячи автоматически созданных словарных ключей — варианты форм и английских артиклей, а не тысячи отдельных переведённых объектов.

## WebTiles — основная версия

В [GitHub Actions](https://github.com/Mr-Vivor/DCSS-RU/actions/workflows/ru.yml) автоматически проверяются словари, C++-движок и браузерный клиент WebTiles. Артефакт `dcss-ru-web-ubuntu24` содержит сервер и игру для Ubuntu 24.04; `dcss-ru-web-smoke` — журнал и снимок проверки Chromium. Проверенные сборки автоматически устанавливаются на VPS; сохранения и аккаунты лежат отдельно от релизов. Адрес сайта — `https://dungeoncrawl.ru/`; первая активация HTTPS ожидает готовности DNS. Настройка сервера описана в [ops/webtiles/README.md](ops/webtiles/README.md).

Для локального запуска на Linux из `crawl-ref/source/` (или корня распакованной сборки):

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r webserver/requirements/base.py3.txt
```

Создайте `webserver/config.yml`:

```yaml
dgl_mode: false
bind_address: 127.0.0.1
bind_port: 8080
```

Запустите `LANG=C.UTF-8 python webserver/server.py` и откройте `http://127.0.0.1:8080/`. Для сборки из исходников предварительно выполните `make -j2 WEBTILES=y`. Настройки публичного сервера описаны в [README WebTiles](crawl-ref/source/webserver/README.md).

Windows-клиент автоматически больше не собирается. Старая предварительная сборка остаётся доступна; новая запускается только вручную через `Run workflow` с опцией `build_windows`.

В рабочей папке Windows локальный WebTiles запускается через проектную среду Cygwin: `powershell -File tools/ru/serve-local-web.ps1`. Сервер работает в этом терминале до Ctrl+C. Это совместимая среда для веб-движка, отдельный настольный клиент не требуется.

Пока сборка не зелёная, это исходники для разработки. Полные инструкции сборки upstream находятся в [INSTALL.md](crawl-ref/INSTALL.md).

## Исправить название или падеж

1. Найдите объект в `localization/ru/entities.json`.
2. Исправьте нужные формы и при необходимости статус `review`.
3. Выполните `python tools/ru/generate.py`.
4. Проверьте `python -m unittest discover -s tools/ru/tests -v`.

Игра и вики обновятся из одного источника. Названия находятся в `localization/ru/terms.json`; политика транслитерации и точный объём этого прохода — в [POLICY.md](localization/ru/POLICY.md). Статичные подписи редактируются в `localization/ru/static.json`, описания персонажей — в `character-descriptions.json`, вступления богов — в `god-introductions.json`. Обучение, подсказки, силы и гнев богов — в `crawl-ref/source/dat/descript/ru/`. Не редактируйте сгенерированные словари и карточки вики вручную.

Проверенные описания предметов, навыков и свойств редактируются в `localization/ru/descriptions.json`. В каждой записи сохранён отпечаток английского источника: при изменении механик upstream генератор потребует повторной проверки. В Lua разрешены только явно перечисленные переводы строк; условия и программные имена сохраняются. `context-review.json` фиксирует контекст и состояние вычитанных системных каталогов. Остальные черновики ещё требуют проверки.

`localization/ru/message-coverage.json` содержит покрытие сообщений по исходным разделам. Проверка `python tools/ru/message_catalog.py --summary` показывает пропуски. Для подготовки дополнений `--sections ability.cc main.cc` выводит исходные шаблоны с локальными номерами; `--apply путь.txt` принимает вычитанные строки `номер | перевод`. Номера защищены отпечатком английского каталога, параметры и разметка проверяются до записи. После дополнений запустите генератор.

В `localization/ru/seed.tsv` сохранён исходный список предложенных терминов. Формы однажды предложены с помощью pymorphy3 и требуют вычитки; обычная генерация использует только стандартную библиотеку Python, а самой игре Python-морфология не нужна.

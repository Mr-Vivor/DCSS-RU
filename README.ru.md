# DCSS-RU

Русский форк Dungeon Crawl Stone Soup. Первый проход: понятный перевод с постепенным исправлением падежей и терминов.

Основа: crawl/crawl, trunk от 25 октября 2026 года (`60e87af`). Языковой слой перенесён из [Alphabet Soup](https://github.com/powerbf/alphabet-soup/tree/i18n-master), коммит `c15f1bd`, с сохранением исходной атрибуции. Механика игры следует выбранной версии upstream.

## Текущее состояние

- Русский включён по умолчанию; для английского укажите `language = en` в настройках.
- Общий словарь: 92 монстра и 99 предметов, формы шести падежей и числа.
- Дополнительно: 27 видов персонажей, 28 предысторий и 29 навыков в общем словаре игры и вики.
- Первый набор сообщений боя, предметов, состояний и подписей интерфейса.
- Существующие русские описания upstream сохранены.
- В `wiki/ru/` генерируются карточки терминов и данные будущей вики. Для ледяного дракона, зелья исцеления и свитка телепортации добавлены первые статьи; остальные карточки пока черновые.
- Отсутствующий перевод отображается на английском. Неточные формы исправляются постепенно.

Это начало локализации, а не заявление о переводе 50% игры. Тысячи автоматически созданных словарных ключей — варианты форм и английских артиклей, а не тысячи отдельных переведённых объектов.

## Скачать и запустить

Предварительные сборки публикуются как артефакты задания [DCSS-RU](https://github.com/Mr-Vivor/DCSS-RU/actions/workflows/ru.yml). После успешной сборки откройте запуск и скачайте `dcss-ru-windows-tiles`, распакуйте оба вложенных архива и запустите `crawl.exe` внутри папки игры. Для загрузки артефактов GitHub может потребоваться вход.

Пока сборка не зелёная, это исходники для разработки. Полные инструкции сборки upstream находятся в [INSTALL.md](crawl-ref/INSTALL.md).

## Исправить название или падеж

1. Найдите объект в `localization/ru/entities.json`.
2. Исправьте нужные формы и при необходимости статус `review`.
3. Выполните `python tools/ru/generate.py`.
4. Проверьте `python -m unittest discover -s tools/ru/tests -v`.

Игра и вики обновятся из одного источника. Названия видов, предысторий и навыков находятся в `localization/ru/terms.json`. Не редактируйте сгенерированные `entities.txt`, `terms.txt` и карточки вики вручную. Сообщения и интерфейс пока редактируются в `crawl-ref/source/dat/translate/ru/messages.txt` и `ui.txt`.

В `localization/ru/seed.tsv` сохранён исходный список предложенных терминов. Формы однажды предложены с помощью pymorphy3 и требуют вычитки; обычная генерация использует только стандартную библиотеку Python, а самой игре Python-морфология не нужна.
